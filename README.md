# C Day 96 - Hospital Patient Management System

## Description
A menu-driven Hospital Patient Management System developed using C. It manages basic patient records and stores them in a text file.

## Features
- Add new patients
- Display all patients
- Search patients by ID
- Update patient bills
- Discharge patients
- Save records permanently

## Files
- `hospital.c` - Main C program
- `patients.txt` - Patient records

## How to Compile
`gcc hospital.c -o hospital`

## How to Run
Windows: `hospital.exe`

Linux: `./hospital`

Keep `patients.txt` in the program's working directory.

## Concepts Used
- Structures
- Arrays
- Functions
- File Handling
- Searching
- Updating and Deleting Records
